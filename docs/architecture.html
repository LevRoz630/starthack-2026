UNRISKOMEGA · Look Mom I am Quant

Ping to Pitch

One fact engine feeds two places: a laptop dashboard for the one-click briefing, and a phone that keeps answering while a client is on the line. A checker sits between the model and anything spoken, so nothing reaches the advisor unless the data backs it up.

Why the checker exists

Apertus writes the sentence, but a sentence is only kept if every number and every rule name in it also appears in the facts it was given. If it adds something the data didn't say, the plain fact sentence is used instead. Either way the advisor never sees an unchecked line.

Two surfaces, one backend

The dashboard is the one-click version for a desk: pick a client, read the briefing, see the source under each line. The phone runs the same code, but the trigger is a ringing call instead of a click.

What's real and what's replayed

Market moves in the demo replay from a recorded file, and that's said out loud on stage. The same code takes a live feed; a Yahoo Finance snapshot already runs as one working example.

Some answers are a chain

"Where did it go" or "why less than the index" get a path through a small graph of facts: the total, the parts it came from, what held up. Every step is a fact and every link is a dependency the engine already computed, so a chain can be checked one step at a time. Other questions go through simpler layers: the question's type, then the model choosing among the facts, then a keyword match.
